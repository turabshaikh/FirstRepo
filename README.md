# Nutanix Learning Studio

A practical Nutanix administration and architecture learning website by **Turab Shaikh**.

## Website focus

- Nutanix HCI architecture and fundamentals
- AOS, AHV, CVM, and Prism Element / Prism Central
- Cluster administration, lifecycle operations, and troubleshooting
- Data protection, replication, recovery, and disaster recovery
- VMware-to-Nutanix migration planning
- Nutanix Files and Self-Service
- Monitoring, performance, and architecture fundamentals

This is independent, experience-led technical training. It is not an official Nutanix course or certification program and is not affiliated with or endorsed by Nutanix, Inc.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment → Source**, select **GitHub Actions**.
3. Open the **Actions** tab and run **Deploy website to GitHub Pages** if the first push did not deploy automatically.
4. Once the workflow succeeds, open the Pages URL shown in the deployment job.

The workflow deploys the root `index.html` on every push to `master`.
